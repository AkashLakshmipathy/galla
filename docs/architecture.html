State & evidence

Firestore · asia-south1 shop · parties · catalog · inventory orders · purchases · khata_imports · confirm_queue · gst_registers
One transaction ledger + parties.credit.outstanding Append-only. Corrections are reversing entries. stock_applied guards against a Pub/Sub redelivery doubling stock.
Product & audit, one collection agent_traces Every step: agent, status, duration, model, tokens, one-line output. Drives the on-screen trace strip and the audit log.
Cloud Storage galla-media Voice notes, bill and khata photos, quotation and GST PDFs, CSV registers.
The LLM never decides money.It extracts and it explains. Deterministic Python rules produce every verdict, and rule_fired is persisted on each one, so any decision can be reproduced and explained months later.
Every model call has a fallback.No credentials, a bad response or an API error falls through to a deterministic path. A demo never shows an empty state because a call failed.
Asynchronous by construction.Ingestion returns before the agents run. Pub/Sub carries the work; the trace document is how the phone finds out it finished.
